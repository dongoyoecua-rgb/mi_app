# Mi Primera Aplicación en Flutter

## Mi Perfil Profesional

Aplicación desarrollada en Flutter como parte de la Actividad Integradora "Mi Primera Aplicación en Flutter".

La aplicación presenta información profesional del estudiante y demuestra el uso de widgets básicos, interacción con el usuario, instalación de un paquete externo, ejecución en un emulador Android y publicación del proyecto en GitHub.

---

## Autor

**Gregorio Garzón**

---

## Objetivo

Desarrollar una aplicación básica utilizando Flutter, aplicando widgets fundamentales y conceptos de interacción para construir una interfaz sencilla, ordenada y funcional.

---

## Descripción de la aplicación

La aplicación "Mi Perfil Profesional" presenta información relacionada con la formación y experiencia del estudiante.

La pantalla principal incluye:

- Nombre del estudiante.
- Formación académica.
- Experiencia profesional.
- Habilidades tecnológicas.
- Herramientas utilizadas.
- Objetivo profesional.

La aplicación también incluye un botón interactivo que permite mostrar u ocultar el objetivo profesional.

## Interacción

La aplicación cuenta con un botón denominado:

**Mostrar mi objetivo**

Al presionarlo, se muestra la sección de objetivo profesional.

Al presionarlo nuevamente, la información se oculta.

---

## Paquete externo

Para mejorar el diseño visual de la aplicación se utilizó el paquete:

**google_fonts**

Versión utilizada:

`8.2.1`

El paquete permite utilizar fuentes adicionales de Google Fonts dentro de la aplicación.
